# Blobtide ASO (store ranking)

Stores rank on title/subtitle, icon, screenshots, retention, and crash-free rate — not Google web SEO. Web SEO only helps the GitHub Pages game.

- D1 retention above ~35% and crash-free 99.5%+ beat keyword stuffing.
- Soft launch: Play closed testing in 2–3 countries, watch `level_fail` vs `level_win` on L1–L5.
