# Blobtide GDD (one page)

**Fantasy:** You are a tide of glowing slime. One thumb. Grow or die.

**Camera:** Portrait 9:16, behind/above, gate numbers must read on a mute Reel.

**Rules:** The whole crowd is one number. A gate applies once (`+ - x ÷`). Saws/walls subtract. Holes take ~30%. Door HP: if count >= HP you win.

**Fail:** count hits 0, or door is taller than you.

**Win:** coins = `10 + leftover + levelIndex` (optional 2x rewarded).

**Progression:** linear 56 levels, unlock next on win. Cosmetics only — no pay-to-win gates.

**Theme:** dark track, lime/cyan slime, original look (not Count Masters assets).
